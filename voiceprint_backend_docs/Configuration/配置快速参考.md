# 配置快速参考

本文档提供针对不同部署场景的关键配置项快速参考。

## 部署模式对比

| 配置项 | LowResource (边缘设备) | HighPerformance (数据中心) |
|--------|------------------------|---------------------------|
| **数据库** | SQLite | PostgreSQL + TDengine |
| **Hangfire 存储** | Memory | SQLite / Redis |
| **Redis** | 禁用 | 可选启用 |
| **Swagger** | 建议禁用 | 可选启用 |
| **日志保留** | 10 天 (全量) / 30 天 (错误) | 3 天 (全量) / 7 天 (错误) |
| **声纹采集** | 默认禁用 | 默认启用 |
| **IEC61850 上报** | 默认禁用 | 默认启用 |

---

## 1. 边缘设备部署配置

**适用场景**: ARM32 边缘计算设备、资源受限环境、单机部署

### 核心配置 (`appsettings.LowResource.json`)

```json
{
  "App": {
    "SelfUrl": "http://*:19001",
    "EnableSwagger": false  // ⚠️ ARM32 平台必须禁用以避免栈溢出
  },
  "DbConnOptions": {
    "DeploymentMode": "LowResource",
    "Url": "Data Source=db/ast_intellisub.db",
    "DbType": "Sqlite",
    "TDengineUrl": "",  // 低资源模式不使用 TDengine
    "EnabledCodeFirst": true,
    "EnabledSaasMultiTenancy": false
  },
  "Hangfire": {
    "StorageMode": "Memory"  // 重启后任务丢失
  },
  "Redis": {
    "IsEnabled": false
  },
  "Serilog": {
    "WriteTo": [
      {
        "Name": "File",
        "Args": {
          "path": "logs/all/log-.txt",
          "retainedFileCountLimit": 10,
          "fileSizeLimitBytes": 20971520
        }
      }
    ]
  }
}
```

### 关键禁用项

```json
{
  "VoiceprintCaptureJob": {
    "Enabled": false  // 边缘设备默认不采集声纹
  },
  "Iec61850": {
    "EnableDataReport": false,
    "EnableAlarmReport": false
  },
  "EnvironmentDetectionCollection": {
    "Enabled": false
  },
  "InfraredTemperatureCollection": {
    "Enabled": false
  }
}
```

## 10. 环境变量覆盖

支持通过环境变量覆盖配置项：

```bash
# 数据库连接
export DbConnOptions__Url="Host=localhost;Database=ast_db;..."

# Redis 配置
export Redis__IsEnabled="true"
export Redis__Configuration="localhost:6379"

# JWT 密钥
export JwtOptions__SecurityKey="your-secret-key"

# 部署模式
export DbConnOptions__DeploymentMode="HighPerformance"
```

## 12. 常见配置组合

### ARM32 边缘设备 (最低配置)
- 使用 `appsettings.LowResource.json`
- 禁用 Swagger
- 禁用声纹采集
- 禁用 IEC61850 上报
- 使用 SQLite + Memory 存储

### x64 边缘设备 (标准配置)
- 使用 `appsettings.json`
- 启用 Swagger
- 启用声纹采集
- 禁用 IEC61850 上报
- 使用 SQLite + Memory 存储

### 数据中心节点 (高性能配置)
- 使用 `appsettings.HighPerformance.json`
- 启用所有功能
- 使用 PostgreSQL + TDengine
- 使用 SQLite/Redis 存储 Hangfire
