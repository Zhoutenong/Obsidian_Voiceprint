## 每篇文档最低内容要求

### 服务 / Manager 文档

1. **概述** — 职责、所在层、依赖注入生命周期
2. **接口列表** — 公开方法或 HTTP 端点（路径、方法、权限）
3. **核心流程** — Mermaid 流程图或时序图
4. **配置项** — 相关 `appsettings` 节
5. **相关文档** — 双向链接

### Host / Framework 文档

1. **在系统中的位置** — 依赖图
2. **关键类与扩展点** — 如何自定义
3. **配置与开关** — 部署模式差异
4. **常见问题** — 链接 `Issues/` 如有

### 实体文档

1. **表名与主键**
2. **字段列表**（类型、说明、外键）
3. **关联实体** — ER 关系
4. **被哪些服务读写**
