## 日志查看

### 日志位置

```
logs/
├── all/                    # 全部日志
│   ├── log-20260601.txt
│   └── log-20260602.txt
└── error/                  # 错误日志
    ├── log-error-20260601.txt
    └── log-error-20260602.txt
```

### 日志配置

```json
{
  "Serilog": {
    "MinimumLevel": {
      "Default": "Information",
      "Override": {
        "Microsoft": "Warning",
        "Microsoft.EntityFrameworkCore": "Warning",
        "System": "Warning"
      }
    },
    "WriteTo": [
      {
        "Name": "File",
        "Args": {
          "path": "logs/all/log-.txt",
          "rollingInterval": "Day",
          "retainedFileCountLimit": 30,
          "outputTemplate": "{Timestamp:yyyy-MM-dd HH:mm:ss.fff} [{Level:u3}] [{SourceContext}] {Message:lj}{NewLine}{Exception}"
        }
      }
    ]
  }
}
```

### 实时查看日志

```bash
# 实时查看全部日志
tail -f logs/all/log-$(date +%Y%m%d).txt

# 查看错误日志
tail -f logs/error/log-error-$(date +%Y%m%d).txt

# 搜索特定错误
grep -i "error" logs/all/*.txt

# 搜索 TDengine 相关日志
grep "TDengine" logs/all/*.txt

# 搜索告警相关日志
grep "告警\|Alarm" logs/all/*.txt
```

### Windows PowerShell

```powershell
# 实时查看日志
Get-Content "logs\all\log-$(Get-Date -Format 'yyyyMMdd').txt" -Wait

# 搜索错误
Select-String -Path "logs\all\*.txt" -Pattern "error"

# 搜索特定模块
Select-String -Path "logs\all\*.txt" -Pattern "Voiceprint"
```

### 日志级别调整

临时修改 `appsettings.json` 提高日志级别：

```json
{
  "Serilog": {
    "MinimumLevel": {
      "Default": "Debug"
    }
  }
}
```

## Hangfire Dashboard

### 访问 Dashboard

```
URL: http://localhost:5000/hangfire
认证: 默认无认证（生产环境建议配置）
```

### 功能说明

**Jobs 标签页**:
- 查看所有后台任务
- 查看任务执行历史
- 手动触发任务

**Recurring Jobs**:
- 查看定时任务
- 编辑 Cron 表达式
- 立即触发/暂停

**Retries**:
- 查看失败重试任务
- 查看重试原因

### 关键任务

| 任务名称 | Cron 表达式 | 说明 |
|---------|-------------|------|
| VoiceprintCaptureJob | `0 */10 * * * *` | 每10分钟采集音频 |
| VoiceprintProcessedCleanupJob | `0 0 2 * * *` | 每天凌晨2点清理 |
| PointDataCleanupJob | `0 0 3 * * *` | 每天凌晨3点清理 |

### 调试技巧

**查看任务执行日志**:
1. 在 Dashboard 中点击任务
2. 查看 Job History
3. 点击执行记录查看详情

**手动触发任务**:
```csharp
// 在 Hangfire Dashboard 中点击 "Trigger now"
// 或通过代码触发
BackgroundJob.Enqueue<VoiceprintCaptureJob>(job => job.ExecuteAsync());
```

**任务失败排查**:
1. 查看 Exception 消息
2. 检查日志文件中的完整堆栈
3. 验证任务所需依赖是否可用

## 数据库调试

### SQLite 调试

```bash
# 连接到 SQLite 数据库
sqlite3 db/ast_intellisub.db

# 查看所有表
.tables

# 查看表结构
.schema ast_pointdata

# 执行查询
SELECT * FROM ast_alarm_record ORDER BY alarm_time DESC LIMIT 10;

# 退出
.quit
```

### 可视化工具

**推荐工具**:
- **DB Browser for SQLite** (https://sqlitebrowser.org/)
- **DBeaver** (支持多数据库)

**使用步骤**:
1. 打开工具，连接到 `db/ast_intellisub.db`
2. 浏览表结构和数据
3. 执行 SQL 查询
4. 查看执行计划

### 常用查询

```sql
-- 查看最近的告警
SELECT * FROM ast_alarm_record 
ORDER BY alarm_time DESC 
LIMIT 20;

-- 查看设备状态
SELECT * FROM ast_monitored_object 
WHERE is_deleted = 0;

-- 查看声纹记录
SELECT * FROM ast_device_audio_record 
ORDER BY collected_at DESC 
LIMIT 10;

-- 统计告警次数
SELECT monitored_object_id, COUNT(*) as count 
FROM ast_alarm_record 
GROUP BY monitored_object_id;
```

### TDengine 调试

```bash
# 连接到 TDengine
taos -h 192.168.3.111 -P 6030 -u root -p taosdata

# 使用数据库
USE ast;

# 查看超级表
SHOW STABLES;

# 查询子表
SELECT * FROM ast_pointdata LIMIT 10;

-- 查看表结构
DESCRIBE ast_pointdata;
```

### LINQ 调试

```csharp
// 在代码中打印生成的 SQL
var sql = _repository._DbQueryable.ToSqlString();
_logger.LogInformation($"Generated SQL: {sql}");

// 查看查询计划
var query = _repository._DbQueryable
    .Where(x => x.MonitoredObjectId == deviceId)
    .ToList();
```

## API 调试

### Swagger UI

```
开发环境: http://localhost:5000/swagger
注意: ARM32 平台建议禁用 Swagger
```

### 使用 curl 测试

```bash
# 登录获取 Token
curl -X POST http://localhost:5000/api/app/account/login \
  -H "Content-Type: application/json" \
  -d '{"userName":"admin","password":"1q2w3E*"}'

# 使用 Token 访问 API
curl -X GET http://localhost:5000/api/app/monitored-object/all \
  -H "Authorization: Bearer YOUR_TOKEN"

# 上传声纹数据
curl -X POST http://localhost:5000/api/app/voiceprint/audio/create \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@audio.wav" \
  -F "monitoredObjectId=device-123"
```

### 使用 Postman

**导入集合**:
1. 从项目根目录导入 Postman Collection
2. 设置环境变量 (BaseURL, Token)
3. 运行测试请求

### SignalR 实时调试

```javascript
// 在浏览器控制台连接 SignalR
const connection = new signalR.HubConnectionBuilder()
    .withUrl("http://localhost:5000/hubs/alarm")
    .build();

connection.on("ReceiveAlarm", (alarm) => {
    console.log("收到告警:", alarm);
});

connection.start().then(() => {
    console.log("SignalR 已连接");
});
```

## 常见问题排查

### 问题 1: 应用启动失败

**排查步骤**:
1. 检查 `appsettings.json` 配置是否正确
2. 确认数据库文件权限
3. 查看日志文件 `logs/all/log-*.txt`

**常见原因**:
- 数据库文件被占用
- 配置文件 JSON 格式错误
- 端口被占用

### 问题 2: 后台任务不执行

**排查步骤**:
1. 访问 Hangfire Dashboard 查看任务状态
2. 检查任务是否启用 (`appsettings.json` 中的 `Enabled: true`)
3. 查看 Cron 表达式是否正确

**常见原因**:
- Hangfire 存储配置错误
- 任务被禁用
- Cron 表达式语法错误

### 问题 3: 数据库连接超时

**排查步骤**:
1. 检查数据库服务是否运行
2. 验证连接字符串是否正确
3. 查看数据库连接数限制

**解决方案**:
参见 [TDengine连接超时问题](./TDengine连接超时问题.md)

### 问题 4: 告警不触发

**排查步骤**:
1. 检查设备是否在线
2. 查看传感器数据是否正常上报
3. 检查告警策略配置

**调试命令**:
```sql
-- 查看最近的传感器数据
SELECT * FROM ast_pointdata 
WHERE device_id = 'your-device-id' 
ORDER BY ts DESC 
LIMIT 10;

-- 查看告警策略配置
SELECT * FROM ast_data_strategy;
```
