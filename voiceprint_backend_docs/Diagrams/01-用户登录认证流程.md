# 用户登录认证流程时序图

## 流程说明

用户通过前端登录界面输入用户名和密码，后端验证身份后返回 JWT Token，前端存储 Token 并用于后续所有 API 调用。

## 时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 👤 用户
    participant Frontend as 🌐 前端应用
    participant API as 🔌 API 网关
    participant AccountService as 📦 账户服务
    participant AuthService as 🔐 认证服务
    participant Database as 💾 数据库

    Note over User,Database: 登录阶段
    User->>Frontend: 输入用户名和密码
    Frontend->>Frontend: 表单验证
    Frontend->>API: POST /api/app/account/login<br/>{ username, password }
    API->>AuthService: 验证用户凭证
    AuthService->>Database: 查询用户信息
    Database-->>AuthService: 用户数据
    AuthService->>AuthService: 验证密码<br/>生成 JWT Token
    AuthService-->>API: 返回 Token + 用户信息
    API-->>Frontend: HTTP 200 OK<br/>{ token, userInfo }
    Frontend->>Frontend: 存储 Token 到 localStorage

    Note over User,Database: 获取账户信息阶段
    Frontend->>API: GET /api/app/account<br/>Authorization: Bearer {token}
    API->>AccountService: 验证 Token 并获取账户信息
    AccountService-->>API: 返回当前用户详细信息
    API-->>Frontend: { id, name, roles, permissions }
    Frontend->>Frontend: 更新应用状态<br/>跳转到主页面

    Note over User,Database: 后续请求（携带 Token）
    loop 每次请求
        Frontend->>API: 任意 API 请求<br/>Authorization: Bearer {token}
        API->>API: 验证 Token 有效性
        Note right of API: Token 有效则处理请求
    end
```

## 关键接口

| 接口 | 方法 | 说明 |
|-----|------|-----|
| `/api/app/account/login` | POST | 用户登录，返回 JWT Token |
| `/api/app/account` | GET | 获取当前账户信息 |
