# 仪表板与巡视流程时序图

## 流程说明

仪表板是系统首页，展示巡视统计、设备状态、告警信息等核心数据。巡视流程包括：巡视记录查询、巡视结果查看、报告生成和导出等功能。

## 时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 👤 用户
    participant Frontend as 🌐 前端应用
    participant API as 🔌 API 网关
    participant DashboardService as 📊 仪表板服务
    participant DeviceService as 📦 设备服务
    participant ReportService as 📄 报告服务
    participant Database as 💾 数据库
    participant FileStorage as 📁 文件存储

    Note over User,FileStorage: 用户打开首页
    User->>Frontend: 访问首页
    Frontend->>Frontend: 并行加载多个数据

    par 并行请求首页数据
        Frontend->>API: GET /api/app/voiceprint/dashboard/overview
        API->>DashboardService: 查询巡视统计
        DashboardService->>Database: 统计巡视天数和采集次数
        Database-->>DashboardService: 统计结果
        DashboardService-->>Frontend: { totalDays, collectionCount }
    and
        Frontend->>API: GET /api/app/voiceprint/dashboard/system-status
        API->>DeviceService: 查询设备状态统计
        DeviceService->>Database: 统计各状态设备数量
        Database-->>DeviceService: 统计结果
        DeviceService-->>Frontend: { normal, warning, fault }
    and
        Frontend->>API: GET /api/app/voiceprint/dashboard/alarms
        API->>DashboardService: 查询最新告警
        DashboardService->>Database: SELECT TOP 10 未处理告警
        Database-->>DashboardService: 告警数据
        DashboardService-->>Frontend: 告警列表
    end

    Frontend->>User: 渲染首页仪表板

    Note over User,FileStorage: 查询巡视记录
    User->>Frontend: 选择日期查看巡视记录
    Frontend->>API: GET /api/app/voiceprint/dashboard/records<br/>?date=2026-06-01
    API->>DashboardService: 查询指定日期的巡视记录
    DashboardService->>Database: SELECT 巡视记录
    Database-->>DashboardService: 记录列表（包含 groupId）
    DashboardService-->>Frontend: 返回记录列表
    Frontend->>User: 显示巡视记录卡片

    Note over User,FileStorage: 查看巡视详情
    User->>Frontend: 点击某条记录查看详情
    Frontend->>API: GET /api/app/voiceprint/dashboard/records/{groupId}
    API->>DashboardService: 查询巡视记录详情
    DashboardService->>Database: SELECT 详细采集数据
    Database-->>DashboardService: 详细数据（音频、告警、结果）
    DashboardService-->>Frontend: 返回详情数据
    Frontend->>User: 显示巡视结果详情

    Note over User,FileStorage: 生成告警报告
    User->>Frontend: 在告警弹窗中点击"生成报告"
    Frontend->>API: POST /api/app/voiceprint/dashboard/generate-alarm-report<br/>{ alarmId, templateId }
    API->>ReportService: 触发报告生成任务
    ReportService->>ReportService: 查询告警详情
    ReportService->>ReportService: 查询相关音频
    ReportService->>ReportService: 生成 DOCX 报告
    ReportService->>FileStorage: 保存报告文件
    FileStorage-->>ReportService: 返回文件路径
    ReportService-->>Frontend: { downloadUrl, filename }
    Frontend->>User: 提示下载或自动下载

    Note over User,FileStorage: 导出智能巡视报表
    User->>Frontend: 点击"导出报告"按钮
    Frontend->>Frontend: 选择日期范围、设备
    User->>Frontend: 确认导出
    Frontend->>API: POST /api/app/voiceprint/reports/export<br/>{ startDate, endDate, deviceIds }
    API->>ReportService: 触发批量导出任务
    ReportService->>Database: 查询日期范围内的所有巡视数据
    Database-->>ReportService: 返回大量巡视记录
    ReportService->>ReportService: 生成汇总报告
    ReportService->>FileStorage: 保存汇总报告
    FileStorage-->>ReportService: 文件路径
    ReportService-->>Frontend: { downloadUrl }
    Frontend->>User: 下载报告文件

    Note over User,FileStorage: 切换算法模式
    User->>Frontend: 切换算法模式（自动/手动）
    Frontend->>API: POST /api/app/voiceprint/algorithm/switch<br/>{ mode: "auto" | "manual" }
    API->>DashboardService: 更新算法配置
    DashboardService->>Database: UPDATE 配置表
    Database-->>DashboardService: 更新成功
    DashboardService-->>Frontend: HTTP 200 OK
    Frontend->>User: 显示模式切换成功
```

## 关键接口

| 接口 | 方法 | 说明 |
|-----|------|-----|
| `/api/app/voiceprint/dashboard/overview` | GET | 巡视统计（总天数、采集次数） |
| `/api/app/voiceprint/dashboard/records` | GET | 获取指定日期的巡视记录 |
| `/api/app/voiceprint/dashboard/records/{groupId}` | GET | 巡视记录详情 |
| `/api/app/voiceprint/dashboard/system-status` | GET | 电子沙盘（设备状态统计） |
| `/api/app/voiceprint/dashboard/alarms` | GET | 首页报警信息 |
| `/api/app/voiceprint/dashboard/generate-alarm-report` | POST | 根据告警生成单次声纹分析报表 |
| `/api/app/voiceprint/reports/export` | POST | 导出智能巡视报表 |
| `/api/app/voiceprint/algorithm/switch` | POST | 切换算法模式 |
