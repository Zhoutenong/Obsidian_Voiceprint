# 告警管理流程时序图

## 流程说明

告警管理包括：实时告警推送（通过 SignalR Hub）、告警列表查询、告警统计、告警处理等流程。系统通过 SignalR Hub（`AlarmNotificationHub`）实时推送告警，同时支持用户主动查询和处理告警。

## 时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 👤 用户
    participant Frontend as 🌐 前端应用
    participant SignalR as 📡 SignalR Hub<br/>(AlarmNotificationHub)
    participant API as 🔌 API 网关
    participant AlarmService as 🚨 告警服务<br/>(VoiceprintPortalAppService)
    participant Database as 💾 数据库

    Note over User,Database: 实时告警推送（SignalR 连接）
    Frontend->>SignalR: 建立 SignalR 连接
    SignalR-->>Frontend: 连接成功
    Note over SignalR,Database: 等待后端推送告警通知...

    par 后端检测到新告警
        AlarmService->>Database: 创建告警记录
        AlarmService->>SignalR: Clients.All.SendAsync("ReceiveAlarmNotification")
        SignalR-->>Frontend: 告警推送通知
        Frontend->>Frontend: 显示告警弹窗/通知
    and 用户查看告警列表
        User->>Frontend: 打开告警记录页面
        Frontend->>API: GET /api/app/voiceprint/alarms<br/>?deviceId=xxx&status=0&startTime=xxx
        API->>AlarmService: 查询告警列表
        AlarmService->>Database: SELECT 告警记录
        Database-->>AlarmService: 告警数据列表
        AlarmService-->>API: 返回分页告警数据
        API-->>Frontend: { items, total }
        Frontend->>User: 显示告警列表
    and 用户查看告警统计
        Frontend->>API: GET /api/app/voiceprint/alarms/monthly-stat
        API->>AlarmService: 查询告警统计数据
        AlarmService->>Database: 统计各维度告警数据
        Database-->>AlarmService: 统计结果
        AlarmService-->>Frontend: { anomalyStats, processingStats, deviceStats }
        Frontend->>User: 显示统计图表
    end

    Note over User,Database: 告警处理流程
    User->>Frontend: 点击"处理告警"按钮
    Frontend->>Frontend: 打开处理对话框
    User->>Frontend: 输入处理说明
    User->>Frontend: 提交处理
    Frontend->>API: PUT /api/app/voiceprint/alarms/{alarmId:guid}<br/>{ status: 1, handleNote: "xxx" }
    API->>AlarmService: 更新告警状态
    AlarmService->>Database: UPDATE 告警记录
    Database-->>AlarmService: 更新成功
    AlarmService-->>API: 返回处理结果
    API-->>Frontend: HTTP 200 OK
    Frontend->>User: 显示处理成功提示
    Frontend->>Frontend: 刷新告警列表

    Note over User,Database: 首页告警面板
    Frontend->>API: GET /api/app/voiceprint/dashboard/alarms
    API->>AlarmService: 查询最新告警（首页展示）
    AlarmService->>Database: SELECT TOP 10 未处理告警
    Database-->>AlarmService: 最新告警数据
    AlarmService-->>Frontend: 返回告警列表
    Frontend->>User: 首页显示告警卡片
```

## 关键接口

| 接口 | 方法 | 说明 |
|-----|------|-----|
| `/api/app/voiceprint/alarms/monthly-stat` | GET | 告警统计（返回 anomalyStats, processingStats, deviceStats 三维度数据） |
| `/api/app/voiceprint/alarms/device-options` | GET | 报警筛选设备下拉选项 |
| `/api/app/voiceprint/alarms` | GET | 报警记录列表（分页） |
| `/api/app/voiceprint/alarms/{alarmId:guid}` | PUT | 处理告警（更新状态和备注） |
| `/api/app/voiceprint/dashboard/alarms` | GET | 首页报警信息（最新未处理告警） |

## 告警统计响应结构 (VoiceprintMonthlyStatDto)

```json
{
  "anomalyStats": [{ "key": "异常类型", "value": 数量 }],
  "processingStats": [{ "key": "处理状态", "value": 数量 }],
  "deviceStats": [{ "deviceName": "设备名", "alarmCount": 数量 }]
}
```

## 实时推送机制

- **SignalR Hub**: `AlarmNotificationHub`（位于 `AlarmNotificationHub.cs`）
- **推送方法**: `Clients.All.SendAsync("ReceiveAlarmNotification", notification)`
- **后端服务**: `AlarmNotificationService` 通过 `IHubContext<AlarmNotificationHub>` 触发推送

## 前端使用位置

- `src/hooks/alarm-record/useAlarmStatistic.ts` - 告警统计
- `src/hooks/alarm-record/useAlarmDeviceOptions.tsx` - 设备选项
- `src/hooks/alarm-record/useAlarmList.ts` - 告警列表
- `src/hooks/alarm-record/useAlarmActions.tsx` - 告警操作
- `src/hooks/alarm-record/useDashboardAlarmList.tsx` - 首页告警
- `src/request/utils/wsRequest.ts` - SignalR 连接配置
