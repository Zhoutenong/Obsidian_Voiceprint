# 告警管理流程时序图

## 流程说明

告警管理包括：实时告警推送、告警列表查询、告警统计、告警处理等流程。系统通过 WebSocket 实时推送告警，同时支持用户主动查询和处理告警。

## 时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 👤 用户
    participant Frontend as 🌐 前端应用
    participant WebSocket as 🔌 WebSocket
    participant API as 🔌 API 网关
    participant AlarmService as 🚨 告警服务
    participant Database as 💾 数据库
    participant SignalR as 📡 SignalR Hub

    Note over User,SignalR: 实时告警推送（WebSocket 连接）
    Frontend->>WebSocket: 建立 WebSocket 连接
    WebSocket-->>Frontend: 连接成功
    Note over WebSocket,SignalR: 等待后端推送...

    par 后端检测到新告警
        AlarmService->>Database: 创建告警记录
        AlarmService->>SignalR: 触发实时推送
        SignalR->>WebSocket: Push 告警消息
        WebSocket-->>Frontend: OnAlarm 告警事件
        Frontend->>Frontend: 显示告警弹窗/通知
    and 用户查看告警列表
        User->>Frontend: 打开告警记录页面
        Frontend->>API: GET /api/app/voiceprint/alarms<br/>?deviceId=xxx&status=0&startTime=xxx
        API->>AlarmService: 查询告警列表
        AlarmService->>Database: SELECT 告警记录
        Database-->>AlarmService: 告警数据列表
        AlarmService-->>API: 返回分页告警数据
        API-->>Frontend: { items, total }
        Frontend->>User: 显示告警列表
    and 用户查看告警统计
        Frontend->>API: GET /api/app/voiceprint/alarms/monthly-stat
        API->>AlarmService: 查询近30天统计
        AlarmService->>Database: 统计各等级告警数量
        Database-->>AlarmService: 统计结果
        AlarmService-->>Frontend: { critical, warning, info }
        Frontend->>User: 显示统计图表
    end

    Note over User,SignalR: 告警处理流程
    User->>Frontend: 点击"处理告警"按钮
    Frontend->>Frontend: 打开处理对话框
    User->>Frontend: 输入处理说明
    User->>Frontend: 提交处理
    Frontend->>API: PUT /api/app/voiceprint/alarms/{alarmId}<br/>{ status: 1, handleNote: "xxx" }
    API->>AlarmService: 更新告警状态
    AlarmService->>Database: UPDATE 告警记录
    Database-->>AlarmService: 更新成功
    AlarmService->>SignalR: 通知告警已处理
    SignalR->>WebSocket: Push 状态更新
    AlarmService-->>API: 返回处理结果
    API-->>Frontend: HTTP 200 OK
    Frontend->>User: 显示处理成功提示
    Frontend->>Frontend: 刷新告警列表

    Note over User,SignalR: 首页告警面板
    Frontend->>API: GET /api/app/voiceprint/dashboard/alarms
    API->>AlarmService: 查询最新告警（首页展示）
    AlarmService->>Database: SELECT TOP 10 未处理告警
    Database-->>AlarmService: 最新告警数据
    AlarmService-->>Frontend: 返回告警列表
    Frontend->>User: 首页显示告警卡片
```

## 关键接口

| 接口 | 方法 | 说明 |
|-----|------|-----|
| `/api/app/voiceprint/alarms/monthly-stat` | GET | 近30天告警统计 |
| `/api/app/voiceprint/alarms/device-options` | GET | 报警筛选设备下拉选项 |
| `/api/app/voiceprint/alarms` | GET | 报警记录列表 |
| `/api/app/voiceprint/alarms/{alarmId}` | PUT | 处理告警（更新状态） |
| `/api/app/voiceprint/dashboard/alarms` | GET | 首页报警信息 |

## 前端使用位置

- `src/hooks/alarm-record/useAlarmStatistic.ts` - 告警统计
- `src/hooks/alarm-record/useAlarmDeviceOptions.tsx` - 设备选项
- `src/hooks/alarm-record/useAlarmList.ts` - 告警列表
- `src/hooks/alarm-record/useAlarmActions.tsx` - 告警操作
- `src/hooks/alarm-record/useDashboardAlarmList.tsx` - 首页告警
- `src/request/utils/wsRequest.ts` - WebSocket 配置
