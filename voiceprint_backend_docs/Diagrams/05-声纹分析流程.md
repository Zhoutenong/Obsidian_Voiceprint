# 声纹分析流程时序图

## 流程说明

声纹分析模块包括：标准音频库管理、测试音频导入与识别、从音频生成报告等功能。用户可以上传测试音频进行声纹比对，并生成分析报告。

## 时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 👤 用户
    participant Frontend as 🌐 前端应用
    participant API as 🔌 API 网关
    participant VoiceprintService as 🎵 声纹服务
    participant RecognitionService as 🔍 识别服务
    participant ReportService as 📄 报告服务
    participant FileStorage as 📁 文件存储
    participant Database as 💾 数据库
    participant EdgeDevice as 📡 边缘设备

    Note over User,EdgeDevice: 查询标准音频库
    User->>Frontend: 打开声纹分析页面
    Frontend->>API: GET /api/app/voiceprint/standard-audios<br/>?page=1&limit=20
    API->>VoiceprintService: 查询标准音频库
    VoiceprintService->>Database: SELECT 标准音频
    Database-->>VoiceprintService: 标准音频列表
    VoiceprintService-->>Frontend: { items, total, page }
    Frontend->>User: 显示标准音频列表

    Note over User,EdgeDevice: 上传测试音频进行识别
    User->>Frontend: 选择测试音频文件
    User->>Frontend: 点击"导入并识别"
    Frontend->>Frontend: 创建 FormData<br/>{ file, deviceId, deviceName }
    Frontend->>API: POST /api/app/voiceprint/test-audios/import<br/>Content-Type: multipart/form-data
    API->>VoiceprintService: 处理音频导入
    VoiceprintService->>FileStorage: 保存原始音频文件
    FileStorage-->>VoiceprintService: 文件路径
    VoiceprintService->>Database: 创建测试音频记录
    Database-->>VoiceprintService: 记录创建成功（audioId）
    VoiceprintService->>RecognitionService: 触发声纹识别
    Note right of RecognitionService: 调用边缘设备<br/>或云端 AI 服务

    alt 识别成功
        RecognitionService->>EdgeDevice: 发送音频进行识别
        EdgeDevice-->>RecognitionService: 返回识别结果<br/>{ similarity, matchedId, confidence }
        RecognitionService->>Database: 保存识别结果
        RecognitionService-->>VoiceprintService: 识别完成
        VoiceprintService-->>API: { audioId, similarity, result }
        API-->>Frontend: HTTP 200 OK
        Frontend->>User: 显示识别结果
        Frontend->>User: 提示"识别成功，相似度 85%"
    else 识别失败
        RecognitionService-->>VoiceprintService: 识别失败
        VoiceprintService-->>API: { error: "识别失败" }
        API-->>Frontend: HTTP 500 Error
        Frontend->>User: 显示错误提示
    end

    Note over User,EdgeDevice: 从音频生成报告
    User->>Frontend: 在标准音频库中选择音频
    User->>Frontend: 点击"生成报告"
    Frontend->>API: POST /api/app/voiceprint/reports/generate-from-audio<br/>{ audioId, templateId }
    API->>ReportService: 从音频生成报告
    ReportService->>Database: 查询音频详细信息
    Database-->>ReportService: 音频数据（名称、路径、识别结果）
    ReportService->>ReportService: 生成 DOCX 报告
    Note right of ReportService: 填充报告模板<br/>插入音频信息<br/>添加图表
    ReportService->>FileStorage: 保存报告文件
    FileStorage-->>ReportService: 报告文件路径
    ReportService-->>API: { downloadUrl, filename }
    API-->>Frontend: HTTP 200 OK
    Frontend->>Frontend: 创建 <a> 标签
    Frontend->>User: 自动下载报告文件

    Note over User,EdgeDevice: 批量导入测试音频
    User->>Frontend: 选择多个测试音频
    User->>Frontend: 点击"批量导入"
    loop 遍历每个音频文件
        Frontend->>API: POST /api/app/voiceprint/test-audios/import<br/>{ file, deviceId }
        API->>VoiceprintService: 处理单个音频
        VoiceprintService->>RecognitionService: 触发识别
        RecognitionService-->>VoiceprintService: 返回结果
        VoiceprintService-->>Frontend: 返回单个结果
    end
    Frontend->>User: 显示批量导入结果<br/>成功 5 个，失败 1 个
```

## 关键接口

| 接口 | 方法 | 说明 |
|-----|------|-----|
| `/api/app/voiceprint/standard-audios` | GET | 标准音频库列表 |
| `/api/app/voiceprint/test-audios/import` | POST | 导入测试音频并触发识别 |
| `/api/app/voiceprint/reports/generate-from-audio` | POST | 从音频生成报告并返回下载路径 |

## 前端使用位置

- `src/hooks/voiceprint/useSampleList.tsx` - 标准音频列表
- `src/hooks/voiceprint/useAnalyze.tsx` - 音频识别
- `src/hooks/voiceprint/useGenerateReportFromAudio.tsx` - 从音频生成报告
