# 设备台账查询流程时序图

## 流程说明

设备台账模块展示变电站设备的层次结构、基础信息、运行趋势、异常分布、巡检日志等。用户可以通过设备树选择设备，查看详细信息和下载相关音频。

## 时序图

```mermaid
sequenceDiagram
    autonumber
    participant User as 👤 用户
    participant Frontend as 🌐 前端应用
    participant API as 🔌 API 网关
    participant AssetService as 📦 设备台账服务
    participant Database as 💾 数据库
    participant TDengine as 📊 时序数据库
    participant FileStorage as 📁 文件存储

    Note over User,FileStorage: 页面初始化
    User->>Frontend: 打开设备台账页面
    Frontend->>API: GET /api/app/voiceprint/assets/tree
    API->>AssetService: 获取设备台账树
    AssetService->>Database: SELECT 设备层次结构
    Database-->>AssetService: 设备树数据
    AssetService-->>Frontend: 返回设备树
    Frontend->>User: 渲染左侧设备树

    Note over User,FileStorage: 查看设备基础信息
    User->>Frontend: 在设备树中选择设备
    Frontend->>Frontend: 更新 URL: ?monitoredObjectId=xxx
    Frontend->>API: GET /api/app/voiceprint/assets/{monitoredObjectId}
    API->>AssetService: 查询设备基础信息
    AssetService->>Database: SELECT 设备详情
    Database-->>AssetService: 设备详细数据
    AssetService-->>Frontend: { name, type, location, status, ... }
    Frontend->>User: 显示设备基础信息卡片

    Note over User,FileStorage: 并行加载设备详细数据
    par 查询设备运行趋势
        Frontend->>API: GET /api/app/voiceprint/assets/{monitoredObjectId}/trend<br/>?startTime=2026-05-01&endTime=2026-06-01
        API->>AssetService: 查询设备运行趋势
        AssetService->>TDengine: 查询时序点位数据
        TDengine-->>AssetService: 返回趋势数据（时序）
        AssetService-->>Frontend: { timestamps, values, labels }
        Frontend->>User: 渲染趋势图表
    and 查询设备异常分布
        Frontend->>API: GET /api/app/voiceprint/assets/{monitoredObjectId}/anomaly-mix<br/>?startTime=2026-05-01&endTime=2026-06-01
        API->>AssetService: 查询设备异常分布
        AssetService->>Database: SELECT 异常记录统计
        Database-->>AssetService: 异常分类统计
        AssetService-->>Frontend: { vibration, temperature, noise, ... }
        Frontend->>User: 渲染异常分布饼图
    and 查询设备巡检日志
        Frontend->>API: GET /api/app/voiceprint/assets/{monitoredObjectId}/logs<br/>?page=1&limit=20
        API->>AssetService: 查询巡检日志
        AssetService->>Database: SELECT 巡检记录
        Database-->>AssetService: 日志列表（分页）
        AssetService-->>Frontend: { items, total, page }
        Frontend->>User: 显示巡检日志列表
    end

    Note over User,FileStorage: 下载处理后的音频
    User->>Frontend: 选择要下载的音频记录
    User->>Frontend: 点击"批量下载"按钮
    Frontend->>API: POST /api/app/voiceprint/assets/{monitoredObjectId}/processed-audios/download<br/>{ audioIds: [1, 2, 3] }
    API->>AssetService: 批量获取音频文件
    AssetService->>FileStorage: 读取音频文件
    FileStorage-->>AssetService: 音频文件流
    AssetService->>AssetService: 打包成 ZIP
    AssetService->>FileStorage: 保存 ZIP 文件
    FileStorage-->>AssetService: ZIP 文件路径
    AssetService-->>Frontend: { downloadUrl, filename }
    Frontend->>User: 自动下载 ZIP 文件

    Note over User,FileStorage: 切换设备
    User->>Frontend: 在设备树中选择另一个设备
    Frontend->>Frontend: 重复上述查询流程
    Note right of Frontend: 使用 React Query 缓存<br/>避免重复请求相同数据
```

## 关键接口

| 接口 | 方法 | 说明 |
|-----|------|-----|
| `/api/app/voiceprint/assets/tree` | GET | 获取设备台账树 |
| `/api/app/voiceprint/assets/{monitoredObjectId}` | GET | 设备基础信息 |
| `/api/app/voiceprint/assets/{monitoredObjectId}/trend` | GET | 设备运行趋势 |
| `/api/app/voiceprint/assets/{monitoredObjectId}/anomaly-mix` | GET | 设备异常分布 |
| `/api/app/voiceprint/assets/{monitoredObjectId}/logs` | GET | 设备巡检日志 |
| `/api/app/voiceprint/assets/{monitoredObjectId}/processed-audios/download` | POST | 批量下载处理后的音频 |

## 前端使用位置

- `src/hooks/ledger/useDeviceTree.ts` - 设备树
- `src/hooks/ledger/useMonitoredObjectAttr.ts` - 设备基础信息
- `src/hooks/ledger/useDeviceTrend.ts` - 设备运行趋势
- `src/hooks/ledger/useAnomalStat.ts` - 异常分布
- `src/hooks/ledger/useLogList.ts` - 巡检日志
- `src/hooks/ledger/useDownloadAudio.ts` - 音频下载
