## 前端接口调用时序图

以下时序图描述了前端与后端 API 之间的交互流程。

### 用户登录认证流程
- **文件**: `01-用户登录认证流程.md`
- **描述**: 用户登录、JWT Token 获取和后续请求认证流程
- **参与者**: 用户、前端应用、API 网关、账户服务、认证服务、数据库
- **关键接口**:
  - POST `/api/app/account/login`
  - GET `/api/app/account`

### 告警管理流程
- **文件**: `02-告警管理流程.md`
- **描述**: 实时告警推送（SignalR）、告警查询、统计和处理流程
- **参与者**: 用户、前端应用、WebSocket、告警服务、数据库、SignalR Hub
- **关键接口**:
  - GET `/api/app/voiceprint/alarms/monthly-stat`
  - GET `/api/app/voiceprint/alarms`
  - PUT `/api/app/voiceprint/alarms/{alarmId}`
  - GET `/api/app/voiceprint/dashboard/alarms`

### 仪表板与巡视流程
- **文件**: `03-仪表板与巡视流程.md`
- **描述**: 首页数据加载、巡视记录查询、报告生成和导出
- **参与者**: 用户、前端应用、仪表板服务、设备服务、报告服务、数据库、文件存储
- **关键接口**:
  - GET `/api/app/voiceprint/dashboard/overview`
  - GET `/api/app/voiceprint/dashboard/records`
  - GET `/api/app/voiceprint/dashboard/records/{groupId}`
  - POST `/api/app/voiceprint/dashboard/generate-alarm-report`
  - POST `/api/app/voiceprint/reports/export`

### 设备台账查询流程
- **文件**: `04-设备台账查询流程.md`
- **描述**: 设备树加载、设备详情查询、趋势分析和日志查看
- **参与者**: 用户、前端应用、设备台账服务、数据库、文件存储
- **关键接口**:
  - GET `/api/app/voiceprint/assets/tree`
  - GET `/api/app/voiceprint/assets/{monitoredObjectId}`
  - GET `/api/app/voiceprint/assets/{monitoredObjectId}/trend`

### 声纹分析流程
- **文件**: `05-声纹分析流程.md`
- **描述**: 标准音频库查询、测试音频导入识别、报告生成
- **参与者**: 用户、前端应用、声纹服务、识别服务、报告服务、文件存储、数据库、边缘设备
- **关键接口**:
  - GET `/api/app/voiceprint/standard-audios`
  - POST `/api/app/voiceprint/test-audios/import`
  - POST `/api/app/voiceprint/reports/generate-from-audio`

## 图表维护说明

### 添加新图表
1. 在 `Diagrams/` 目录创建 Markdown 文件
2. 使用 Mermaid 语法编写图表
3. 在此索引中添加条目

### 图表格式推荐
- **时序图**: Mermaid `sequenceDiagram`
- **架构图**: Mermaid `flowchart` 或 `graph`
- **ERD**: Mermaid `erDiagram`
- **状态机**: Mermaid `stateDiagram`
