# 图表索引

本索引记录所有系统架构图、流程图、数据模型图等可视化资源的位置和用途。

## 系统架构图

### 整体架构
- **文件**: `Diagrams/system-architecture.md`
- **描述**: 展示整个智能变电站监控系统的模块化架构
- **包含内容**:

  - API网关层
  - 业务模块层 (ast-intellisub, ast-voiceprint, isapi等)

## 图表维护说明

### 添加新图表
1. 在对应的子目录创建 Markdown 文件
2. 使用 Mermaid、PlantUML 或嵌入图片
3. 在此索引中添加条目

### 图表格式推荐
- **架构图**: Mermaid flowchart 或 graph
- **时序图**: Mermaid sequenceDiagram
- **ERD**: Mermaid erDiagram
- **状态机**: Mermaid stateDiagram
- **复杂图表**: 使用外部工具生成图片后嵌入
