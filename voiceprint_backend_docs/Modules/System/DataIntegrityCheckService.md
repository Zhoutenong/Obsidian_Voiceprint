# DataIntegrityCheckService (数据完整性检查服务)

## 概述
DataIntegrityCheckService 是系统的数据完整性维护服务，在应用启动时自动执行数据引用完整性检查，并清理无效的数据关联。该服务作为后台托管服务运行，确保数据库引用的完整性。

## 职责
- 系统启动时自动检查数据引用完整性
- 识别并清理无效的点位绑定关系
- 监测项关系（MonitoredObjectItemRel）的外键完整性验证
- 生成详细的检查和清理日志

## 主要接口

### StartAsync
服务启动时执行数据完整性检查

**参数：**
- `cancellationToken` (CancellationToken) - 取消令牌

**执行流程：**
1. 延迟 3 秒启动，确保数据库连接就绪
2. 创建服务作用域
3. 执行点位绑定关系完整性检查
4. 生成检查报告

### StopAsync
服务停止时执行清理操作

**参数：**
- `cancellationToken` (CancellationToken) - 取消令牌

### CheckAndCleanInvalidPointBindingsAsync
检查并清理无效的点位绑定关系（私有方法）

**检查逻辑：**
1. 查询所有点位绑定关系记录
2. 获取所有有效的监测项关系 ID
3. 识别引用不存在监测项关系的无效记录
4. 自动删除无效记录
5. 生成详细的清理报告

## 技术实现

### 生命周期管理
- **实现接口** - `IHostedService`, `ITransientDependency`
- **启动时机** - 应用启动后自动执行
- **执行模式** - 一次性执行，非周期性

### 数据完整性检查策略

#### 点位绑定关系完整性
检查 [[PointBindingRelEntity]] 表中的外键引用：
```csharp
// 无效记录：引用了不存在的 MonitoredObjectItemRelId
invalidBindings = allBindings
    .Where(binding => !validRelIds.Contains(binding.MonitoredObjectItemRelId))
```

#### 清理规则
- 按无效引用 ID 分组统计
- 逐条删除无效记录
- 记录删除失败的项目
- 生成清理统计报告

### 依赖服务
- `ISqlSugarRepository<PointBindingRelEntity, Guid>` - 点位绑定关系仓储
- `ISqlSugarRepository<MonitoredObjectItemRelEntity, Guid>` - 监测项关系仓储

## 数据实体

### PointBindingRelEntity
点位绑定关系实体，包含以下关键字段：
- `Id` - 主键
- `MonitoredObjectItemRelId` - 监测项关系 ID（外键）
- `MonitoredPointId` - 监测点位 ID
- `DataBindingItemId` - 数据绑定项 ID

### MonitoredObjectItemRelEntity
监测项关系实体，被点位绑定关系引用

## 优势特点

### 1. 自动化维护
- 应用启动自动执行，无需人工干预
- 及时清理无效引用，防止数据污染

### 2. 详细日志
- 完整的检查过程记录
- 清晰的清理统计信息
- 失败记录的错误日志

### 3. 安全清理
- 延迟启动确保数据库就绪
- 支持取消令牌控制
- 异常处理不影响主应用启动

### 4. 灵活扩展
- 模块化检查方法
- 易于添加其他完整性检查
- 支持批量操作优化

## 注意事项
- 该服务在每次应用启动时执行一次
- 清理操作不可逆，重要数据建议提前备份
- 删除失败的记录需要人工检查和处理
- 建议定期检查日志以确保数据完整性
