# 变电站监视范围概览

本文档汇总 IntelliSubstation 系统的**主要模块**、**数据流动方式**以及**变电站具体监视内容**，作为阅读监测点位、告警、巡检等细分文档前的总览入口。

---

## 一、数据流动：谁在驱动系统

系统数据流动主要由以下方式驱动，Web API 与 Hangfire 是两条主链路，MQTT 与领域事件作为补充。

| 驱动方式 | 典型入口 | 数据流 |
|----------|----------|--------|
| **Web API** | 前端界面、边缘设备 HTTP 上报、声纹/Python 回调 | HTTP → ApplicationService → Domain/Repository → DB |
| **Hangfire** | 定时采集、巡检调度、数据清理 | Cron → Job → Service → DB / MQTT / 外部设备 |
| **MQTT 长连接** | `MqttMessageBackgroundService` | 网关推送设备状态、指令下发 |
| **领域事件** | `EventHandlers`（点位处理、IEC61850、告警联动等） | 业务完成 → LocalEventBus → Handler 链式处理 |
| **SignalR** | `AlarmNotificationHub` | 告警实时推送到前端 |

### Web API 典型场景

- 运维界面：设备管理、告警查询、巡检配置、报表导出
- 边缘上报：`POST /api/app/point-data`（传感器时序数据）
- 声纹链路：树莓派上传音频、Python 服务回写识别结果
- 工业协议：`Iec61850ApiService` 接收 IEC61850 数据

路由约定：`/api/app/{service-name}/{action}`

### Hangfire 典型任务

| 类别 | Job | 默认频率 |
|------|-----|----------|
| 声纹 | `VoiceprintCaptureJob` / `VoiceprintProcessedCleanupJob` | 10 分钟 / 每小时 |
| 数据采集 | `InfraredTemperatureCollectionJob` / `EnvironmentDetectionCollectionJob` | 3 分钟 / 30 秒 |
| 巡检调度 | `PatrolJobManager` | 每 5 分钟 |
| 系统维护 | `GatewaySyncJob`、`VisualGatewayHealthCheckJob`、`PointDataCleanupJob` 等 | 各异 |

仪表板路径：`/hangfire`

### 点位数据处理示例链路

```
边缘设备 HTTP 上报
  → PointDataService (Web API)
  → AstPointDataService (ast-intellisubdata)
  → 写入 SQLite / TDengine
  → ProcessedPointValueEvent
  → PointValueEventHandler
  → 告警判断 / 缓存更新
```

## 三、监视对象：监视谁

系统采用树形结构：**变电站 → 区域/房间 → 设备 → 监测项 → 监测点**。

### 区域（种子数据示例）

- 35kV 开关室
- #1 / #2 接地变室
- 户外
- 还支持：控制室、继电保护室、蓄电池室

### 主要设备

| 设备类型 | 典型实例 |
|----------|----------|
| 开关柜 | 1#～8# 35kV GIS 中压交流柜 |
| 接地变压器 | 1# / 2# 接地变压器 |
| 油浸式变压器 | 户外油浸式变压器 |

类型枚举中还预留：断路器、互感器、避雷器等；种子数据以**开关柜 + 变压器**为主。

相关实体与服务：[[Classes/Device]]、[[Modules/ast-intellisub/Monitoring/MonitoredObjectService]]、[[Modules/ast-intellisub/Monitoring/MonitoredObjectTypeService]]。

## 四、监视物理量：监视什么

### 开关柜（每面柜典型监测项）

| 监测项 | 监测点 | 主要物理量 |
|--------|--------|-----------|
| **断路器分合闸监测** | 分闸监测、合闸监测 | 分/合闸时间、行程、速度、过冲、反弹、电流波形、储能动作等 |
| **动触头三相温度** | 进线温度、出线温度 | A/B/C 相温度（℃） |
| **二合一局放** | 超声波局放、暂态地局放 | 峰值、放电类型、报警等级 |
| **振动监测** | 振动值 | 振动加速度等 |
| **柜内温湿度** | 柜内温湿度 | 温度（℃）、湿度（%） |
| **声纹声音** | 声纹声音 | 设备状态、告警等级 |

### 油浸式变压器

| 监测项 | 监测点 | 主要物理量 |
|--------|--------|-----------|
| **高频电流局放** | 高频电流局放 | 峰值、放电类型、报警等级 |
| **铁芯接地电流** | 铁芯接地电流 | 电流（A）、报警等级 |
| **油浸式声纹声音** | 声纹声音1、声纹声音2 | 声纹识别结果、告警等级 |

### 接地变压器

| 监测项 | 监测点 | 主要物理量 |
|--------|--------|-----------|
| **特高频局放** | 特高频局放 | 峰值、放电类型、报警等级 |
| **声纹声音** | 声纹声音 | 同上 |

种子数据来源：`module/ast-intellisub/Ast.IntelliSub.SqlSugarCore/DataSeeds/SubstationDataSeed.cs`

## 五、传感器类型（边缘采集能力）

`DeviceSubTypeEnum` 定义了 10 种传感器子类型：

| 枚举值 | 说明 | 对应监测 |
|--------|------|----------|
| 断路器特性监测 | 分合闸机械/电气特性 | 分闸/合闸监测 |
| 无源无线温度监测 | 触头/母线温度 | 动触头三相温度 |
| 二合一局放 | 超声波 + 暂态地 | 二合一局放 |
| 高频电流局放 | 变压器绕组/铁芯 | 高频电流局放 |
| 特高频局放 | 接地变/电缆终端 | 特高频局放 |
| 振动监测 | 机械松动/放电振动 | 振动监测 |
| 声纹声音监测 | 树莓派/边缘录音节点 | 声纹声音 |
| 铁芯接地监测 | 变压器铁芯接地 | 铁芯接地电流 |
| 温湿度监测 | 柜内环境 | 柜内温湿度 |
| 图像识别监测 | 摄像机 + AI | 智能巡视/实时监控 |

详见 [[Modules/ast-intellisub/Monitoring/SensorService]]。

## 六、三种监视方式（数据来源）

监测点按 `DataSrcTypeEnum` 分为三类：

| 类型 | 含义 | 典型场景 |
|------|------|----------|
| **状态监测** (`StateMonitoring`) | 边缘传感器经 MQTT 网关持续上报 | 温度、局放、振动、声纹、分合闸 |
| **智能巡视** (`IntelligentPatrol`) | 摄像机定时抓图 + AI 识别 | 表计读数、设备外观、位置状态 |
| **实时监控** (`RealTimeMonitoring`) | 摄像机实时流 + AI 算法 | 红外测温、环境检测 |

### 对应 Hangfire 与 AI 算法

| 任务 / 算法 | 说明 |
|-------------|------|
| `InfraredTemperatureCollectionJob` | 红外测温（默认每 3 分钟） |
| `EnvironmentDetectionCollectionJob` | 环境检测分析（默认每 30 秒） |
| `PatrolJobManager` + `PatrolExecutionService` | 智能巡视（全面/自定义） |

`AlgorithmTypeEnum` 包括：设备外观检测、表计读数、位置状态、行为检测、环境检测分析、红外测温、声音检测。

相关文档：[[Hangfire/Data/InfraredTemperatureCollectionJob]]、[[Hangfire/Data/EnvironmentDetectionCollectionJob]]、[[Modules/ast-intellisub/Monitoring/RealtimeMonitoringPointService]]、[[Modules/ast-intellisub/Patrol/PatrolExecutionService]]。

## 七、基础设施监视

除一次设备外，系统还监视运行基础设施：

| 对象 | 监视内容 | 相关组件 |
|------|----------|----------|

## 八、告警维度

`AlarmCategoryTypeEnum` 分两大类：

- **设备状态告警** — 局放超标、温度超限、分合闸异常、声纹异常等
- **环境状态告警** — 温湿度超限、AI 识别的环境异常等

内置数据策略示例：温度告警、湿度告警、温度数据保护。

相关文档：[[Modules/ast-intellisub/Alarm/AlarmStrategyOverview]]、[[Modules/ast-intellisub/设备告警流程]]。

## 九、一句话总结

本系统主要监视 **GIS 开关柜 + 接地变 + 油浸式变压器** 的：

1. **电气状态** — 分合闸特性、局放（超声/暂态地/高频/特高频）
2. **热状态** — 触头三相温度、柜内温湿度、红外测温
3. **机械状态** — 振动
4. **声学状态** — 声纹识别（树莓派 + Python 推理）
5. **视觉状态** — 智能巡视、环境检测、表计/外观 AI 识别
6. **运行基础设施** — 网关、采集器、摄像机在线状态
