# 审计日志查询指南

本文档介绍如何查询和使用系统中的审计日志和实体变更记录。

## 概述

系统集成了 ABP Framework 的审计日志功能，自动记录：
- **操作日志**: 用户执行的 API 操作
- **实体变更**: 实体的创建、更新、删除记录
- **异常信息**: 操作过程中发生的异常

---

## 数据模型

### 核心实体

| 实体 | 表名 | 说明 |
|------|------|------|
| `AuditLogAggregateRoot` | `YiAuditLog` | 审计日志主表 |
| `AuditLogActionEntity` | `YiAuditLogAction` | 操作记录（服务、方法、参数） |
| `EntityChangeEntity` | `YiEntityChange` | 实体变更记录 |
| `EntityPropertyChangeEntity` | `YiEntityPropertyChange` | 属性变更详情 |

### AuditLogAggregateRoot 主要字段

```csharp
public class AuditLogAggregateRoot
{
    public Guid Id { get; }                    // 日志 ID
    public string? ApplicationName { get; }     // 应用名称
    public Guid? UserId { get; }               // 用户 ID
    public string? UserName { get; }           // 用户名
    public Guid? TenantId { get; }             // 租户 ID
    public DateTime? ExecutionTime { get; }     // 执行时间
    public int? ExecutionDuration { get; }      // 执行耗时（毫秒）
    public string? ClientIpAddress { get; }    // 客户端 IP
    public string? HttpMethod { get; }         // HTTP 方法
    public string? Url { get; }                // 请求 URL
    public int? HttpStatusCode { get; }       // HTTP 状态码
    public string? Exceptions { get; }         // 异常信息
    public string? Comments { get; }          // 备注
    public string? CorrelationId { get; }     // 关联 ID
    
    // 导航属性
    public List<EntityChangeEntity> EntityChanges { get; }  // 实体变更列表
    public List<AuditLogActionEntity> Actions { get; }      // 操作列表
}
```

### EntityChangeEntity 主要字段

```csharp
public class EntityChangeEntity
{
    public Guid Id { get; }                        // 变更 ID
    public Guid AuditLogId { get; }                // 关联的审计日志 ID
    public DateTime? ChangeTime { get; }           // 变更时间
    public EntityChangeType? ChangeType { get; }   // 变更类型（Created/Updated/Deleted）
    public string? EntityId { get; }               // 实体 ID
    public string? EntityTypeFullName { get; }     // 实体类型全名
    public List<EntityPropertyChangeEntity> PropertyChanges { get; }  // 属性变更列表
}
```

### EntityChangeType 枚举

```csharp
public enum EntityChangeType
{
    Created = 0,   // 创建
    Updated = 1,   // 更新
    Deleted = 2    // 删除
}
```

## 查询审计日志

### 1. 基本查询

通过 `IAuditLogRepository` 进行查询：

```csharp
public class AuditLogQueryService
{
    private readonly IAuditLogRepository _auditLogRepository;

    public AuditLogQueryService(IAuditLogRepository auditLogRepository)
    {
        _auditLogRepository = auditLogRepository;
    }

    // 查询最近的审计日志
    public async Task<List<AuditLogAggregateRoot>> GetRecentLogsAsync(int count = 50)
    {
        return await _auditLogRepository.GetListAsync(
            maxResultCount: count,
            includeDetails: true  // 包含 EntityChanges 和 Actions
        );
    }
}
```

## 使用示例

### 示例 1: 审查用户的敏感操作

```csharp
public async Task ReviewUserOperationsAsync(Guid userId, DateTime fromDate)
{
    var logs = await _auditLogRepository.GetListAsync(
        userId: userId,
        startTime: fromDate,
        sorting: "ExecutionTime desc",
        includeDetails: true
    );

    foreach (var log in logs)
    {
        Console.WriteLine($"时间: {log.ExecutionTime}");
        Console.WriteLine($"操作: {log.HttpMethod} {log.Url}");
        Console.WriteLine($"状态: {log.HttpStatusCode}");
        Console.WriteLine($"耗时: {log.ExecutionDuration}ms");
        
        if (log.Exceptions != null)
        {
            Console.WriteLine($"异常: {log.Exceptions}");
        }
        
        // 查看关联的实体变更
        foreach (var entityChange in log.EntityChanges)
        {
            Console.WriteLine($"  实体变更: {entityChange.ChangeType} {entityChange.EntityTypeFullName}");
        }
        
        Console.WriteLine("---");
    }
}
```

### 示例 2: 追踪实体变更历史

```csharp
public async Task TrackEntityChangesAsync(string entityTypeFullName, string entityId)
{
    var changes = await _auditLogRepository.GetEntityChangesWithUsernameAsync(
        entityTypeFullName: entityTypeFullName,
        entityId: entityId
    );

    Console.WriteLine($"实体 {entityTypeFullName} (ID: {entityId}) 的变更历史:");
    Console.WriteLine();

    foreach (var change in changes)
    {
        Console.WriteLine($"时间: {change.ChangeTime}");
        Console.WriteLine($"操作: {change.ChangeType}");
        Console.WriteLine($"用户: {change.UserName}");
        Console.WriteLine($"审计日志 ID: {change.AuditLogId}");
        
        // 查看属性变更详情
        foreach (var propChange in change.PropertyChanges)
        {
            Console.WriteLine($"  属性: {propChange.PropertyName}");
            Console.WriteLine($"  新值: {propChange.NewValue}");
            Console.WriteLine($"  旧值: {propChange.OldValue}");
        }
        
        Console.WriteLine("---");
    }
}
```

### 示例 3: 性能分析

```csharp
public async Task AnalyzePerformanceAsync(DateTime startDate, DateTime endDate)
{
    // 获取平均执行时长
    var avgDurations = await _auditLogRepository.GetAverageExecutionDurationPerDayAsync(
        startDate: startDate,
        endDate: endDate
    );

    Console.WriteLine("每日平均执行时长:");
    foreach (var (date, duration) in avgDurations)
    {
        Console.WriteLine($"{date:yyyy-MM-dd}: {duration:F2}ms");
    }

    // 查找慢操作
    var slowOperations = await _auditLogRepository.GetListAsync(
        startTime: startDate,
        endTime: endDate,
        minExecutionDuration: 1000,  // 超过 1 秒
        sorting: "ExecutionDuration desc",
        maxResultCount: 20,
        includeDetails: false
    );

    Console.WriteLine("\n慢操作 Top 20:");
    foreach (var op in slowOperations)
    {
        Console.WriteLine($"{op.Url} - {op.ExecutionDuration}ms ({op.UserName})");
    }
}
```

## SQL 直接查询

在某些情况下，可以直接通过 SQL 查询审计日志：

### 查询最近的操作日志

```sql
SELECT 
    Id,
    ExecutionTime,
    UserName,
    HttpMethod,
    Url,
    HttpStatusCode,
    ExecutionDuration,
    ClientIpAddress
FROM YiAuditLog
ORDER BY ExecutionTime DESC
LIMIT 100;
```

### 查询特定用户的操作

```sql
SELECT 
    Id,
    ExecutionTime,
    HttpMethod,
    Url,
    Comments
FROM YiAuditLog
WHERE UserId = 'user-guid-here'
ORDER BY ExecutionTime DESC;
```

### 查询实体变更历史

```sql
SELECT 
    ec.Id,
    ec.ChangeTime,
    ec.ChangeType,
    ec.EntityTypeFullName,
    ec.EntityId,
    al.UserName
FROM YiEntityChange ec
LEFT JOIN YiAuditLog al ON ec.AuditLogId = al.Id
WHERE ec.EntityTypeFullName = 'Yi.Abp.Domain.Entities.Device'
  AND ec.EntityId = 'device-id-here'
ORDER BY ec.ChangeTime DESC;
```

### 查询属性变更详情

```sql
SELECT 
    epc.PropertyName,
    epc.OldValue,
    epc.NewValue,
    ec.ChangeType,
    ec.ChangeTime
FROM YiEntityPropertyChange epc
LEFT JOIN YiEntityChange ec ON epc.EntityChangeId = ec.Id
WHERE ec.EntityId = 'device-id-here'
ORDER BY ec.ChangeTime DESC;
```

## 性能优化建议

### 1. 索引利用

系统已为常用查询字段创建索引：
- `TenantId` + `ExecutionTime`
- `TenantId` + `UserId` + `ExecutionTime`
- `AuditLogId` (用于实体变更查询)
- `TenantId` + `EntityTypeFullName` + `EntityId`

### 2. 分页查询

对于大数据量查询，建议使用分页：

```csharp
public async Task<PagedResultDto<AuditLogAggregateRoot>> GetPagedLogsAsync(
    int skipCount,
    int maxResultCount)
{
    var totalCount = await _auditLogRepository.GetCountAsync();
    var logs = await _auditLogRepository.GetListAsync(
        sorting: "ExecutionTime desc",
        skipCount: skipCount,
        maxResultCount: maxResultCount,
        includeDetails: false  // 不加载关联数据以提高性能
    );

    return new PagedResultDto<AuditLogAggregateRoot>(
        totalCount,
        logs
    );
}
```

### 3. 延迟加载关联数据

仅在需要时加载 `EntityChanges` 和 `Actions`：

```csharp
// 第一次查询不加载关联数据
var logs = await _auditLogRepository.GetListAsync(includeDetails: false);

// 仅对感兴趣的日志加载详情
var logIds = logs.Take(10).Select(x => x.Id).ToList();
var detailedLogs = await _auditLogRepository.GetListAsync(
    // ... 其他过滤条件
    includeDetails: true
);
```

## 注意事项

1. **数据量管理**: 审计日志会快速增长，建议定期清理或归档
2. **敏感信息**: 审计日志可能包含敏感数据，查询时注意权限控制
3. **性能影响**: 包含 `includeDetails: true` 的查询会加载所有关联数据，对性能影响较大
4. **Null 值处理**: 某些字段可能为 `null`（如 `UserId`, `UserName` 在匿名请求时）
5. **字符串截断**: 长字符串字段（如 `Url`, `Exceptions`）在存储时会被截断
